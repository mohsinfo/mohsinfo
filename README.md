## 📌 Featured Projects

### 🏥 [Hospital Readmission Risk Dashboard](https://github.com/mohsinfo/hospital-readmission-risk-dashboard)
End-to-end ML pipeline predicting 30-day readmission risk. XGBoost model + Power BI dashboard used in a real clinical ops workflow. Concentrated 42.3% of readmits into a 22.6% actionable queue — nearly doubling baseline precision.  
`Python` `XGBoost` `Power BI` `Feature Engineering`

`Python` `Statistics` `A/B Testing` `Hypothesis Testing`
